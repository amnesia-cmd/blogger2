# My Daily Blog — Second Iteration

A lightweight static blog experiment built with HTML, CSS, and JavaScript.

## Structure

```text
index.html
style.css
script.js
posts.js
```

## Development

Open `index.html` locally or serve the directory with a static HTTP server.

## Publishing

The project can be deployed to static hosting such as GitHub Pages. Posts exported from the browser can be committed to `posts.js` for permanent publication.

## Status

Learning / prototype project. This repository is retained separately to document an iteration of the blog experiment.
